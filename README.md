## Hi, I'm Nahian 👋

I'm a Master's student in Digital Health at the Hasso Plattner Institute, University of Potsdam, and currently working as a Data Engineer.

My work focuses on building practical data systems that turn messy, real-world data into reliable workflows. I develop Python-based ETL pipelines, integrate APIs, automate data extraction processes, and work on improving the robustness of data pipelines through validation, logging, and iteration.

I also work with AI-assisted data extraction workflows, where LLMs are used to parse, structure, and enrich complex input data. A big part of my work is not just making pipelines run, but making them easier to inspect, debug, and improve over time.

### What I work with

- Python, Pandas, SQL
- ETL pipelines and workflow automation
- API integrations
- Data validation and quality checks
- AI-assisted data extraction
- Git, GitHub, CI workflows
- Google Cloud / Google APIs
- Dashboards and reporting workflows

### Current interests

I'm especially interested in Data Engineering, AI-driven data systems, workflow automation, and building reliable backend/data infrastructure. My academic work also focuses on evaluating Large Language Models in healthcare settings, particularly around retrieval, prompt design, and model reliability.

I like building things that work first, then making them more robust by reading the logs, understanding failure cases, and improving the system step by step.
